# New Sweat Website

New Sweat is a roots rock band based out of Raleigh and Durham, NC. This is the band's public-facing website — built and maintained as a personal side project alongside the music itself. Visit [newsweat.com](https://www.newsweat.com).

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | Angular |
| Hosting | Vercel |

## Features

- Band bio and member info
- Embedded players/Links to streaming platforms (Spotify, Apple Music)
- Upcoming show listings
- Social media integration

## Background

I built the original website for the band back in 2012 using a tool called Drupal Gardens which I had gained experience using during Grad assistantship at UNC Chapel Hill. When that service sunsetted, we migrated to a template service for hosting and that sufficed for a few years. However, the cost kept creeping up and maintaining the site was clunky. Since I began in my Software Development role at SAS, I decided to, once again, apply my new skills to work on our site. I built the site in Angular and initially deployed it through GitHub pages. In order to safely integrate with Google Cloud Console to automatically sync our band calendar with our landing page, I switched to Vercel for hosting.
